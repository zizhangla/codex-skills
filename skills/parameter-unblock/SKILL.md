# 参数不足时继续研究

读取[CNS参数与设备解阻](../cns/references/DEVICE_REFERENCE_AND_UNBLOCKING.md)，只补当前决定需要的参数。优先同源参数推广/无量纲与区间推导，再查论文Methods/SI/作者代码/厂商来源，最后构造明确MODELLED的最小自洽模型。记录来源、单位、相关性、成本、敏感性、强经典与下一判别；当轮完成有范围建设，不能只报告缺参数。

新参数只进入前瞻参考分支；真实设备、冻结运行、消费与预算分别保留。强经典覆盖或科学不可识别要分析机制，不靠假参数救结果。实际平台goal续行与送达分开验证，不恢复研究心跳。

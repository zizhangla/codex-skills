# HoloGuide3D Pattern Example

This is a sanitized structural example derived from the governance patterns that proved useful in HoloGuide3D. It contains no live HoloGuide3D authority, thresholds, current state, credentials, repository location, or executable instruction.

The reusable ideas are:

- a Review Bus whose transport carries identity but not authority;
- a committed `GPT_DECISION.md` that binds round, reviewed commit, result ID, allowed changes, forbidden changes, and acceptance criteria;
- an executor-produced `REVIEW_PACKET.md` that binds sources, results, hashes, negative findings, and claim limits;
- context maps that retain long research history without becoming execution authority;
- append-only forensic audits for Git ancestry, freeze timing, provenance, protocol drift, and bridge failures;
- explicit claim boundaries that separate numerical, protocol-relative, optical, hardware, and publication conclusions.

# 大调查报告结构

报告以决策为中心，篇幅随项目复杂度调整。每个关键事实引用可追溯来源；文献用直接链接，项目资料用明确路径、版本／提交与读取时间。资料未取得时单独列出，避免把缺口藏在脚注。

## 执行结论

- **审计对象与决策时点：** 哪个方向、哪项重大投入即将发生。
- **建议：** 继续／改向／暂缓／停止，以及成立条件与信心限制。
- **当前科学定位：** 现阶段实际属于什么贡献；最强可辩护 claim 是什么。
- **最大机会与最大风险：** 各一至三项，说明其如何改变决策。

|---|---|---|---|
| 逐项填写 | | | |

随后简要说明科学问题及物理／任务合同、理论证明义务、对照公平性、证据链薄弱点、阴性／零效应区间，以及与更广泛原则的距离。若声称“新物理规律”，必须列出相应的反例排除、前瞻和真实系统证据要求。

|---|---|---|---|---|---|
| 先证伪，后扩展 | | | | | |

单列 **kill criteria**：能够推翻旗舰假说的可观测结果及停止范围。指出可保留的较窄贡献，避免把主假说失败误写成整个项目失败。最后列出下一次复审所需的新证据、责任角色及现行授权来源；审计报告不等于执行授权。
